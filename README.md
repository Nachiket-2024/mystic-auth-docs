Documentation site for [MysticAuth](https://github.com/Nachiket-2024/mystic-auth), a full-stack authentication and Policy-Based Access Control (PBAC) authorization template. Built with [Docusaurus](https://docusaurus.io/), deployed to GitHub Pages.

**Live site: [nachiket-2024.github.io/mystic-auth-docs](https://nachiket-2024.github.io/mystic-auth-docs/)**

---

## Running locally

```bash
npm install
npm run start
```

---

## Deploying

Every push to `main` builds the site and publishes it to the `gh-pages`
branch automatically via [`.github/workflows/ci.yml`](.github/workflows/ci.yml),
which GitHub Pages serves from. No manual step needed.
