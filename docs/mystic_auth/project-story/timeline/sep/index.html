Commit 70: 4 September, 2026​

cfae864: "Set up ngrok, Tailscale Funnel local-prod modes and Playwright E2E tests"

  • ngrok and Tailscale Funnel local-prod Docker modes added, with end-to-end tunnel verification.

Commit 71: 4 September, 2026​

5aff4be: "Blocked self-role privilege escalation, patched security headers and Docker images"

Security hardening driven by a manual adversarial pentest by Claude Code and an automated audit scan (Bandit/ZAP/testssl.sh/pip-audit/npm audit) against the local-prod-ngrok stack, both checked into the repo for reference.

  • The pentest's one real finding, fixed: a caller holding only users:assign_role could relabel themselves to admin via PATCH /users/{email}/role or its bulk counterpart. Not exploitable today (nothing branches on role == "admin"), but a real escalation path waiting for the first downstream shortcut that does. Now rejected outright (403 CANNOT_CHANGE_OWN_ROLE), with regression tests.
  • COOP/CORP/COEP added on backend and nginx; frontend CSP tightened; HSTS moved onto the real TLS terminator; nginx server_tokens off.
  • Base images bumped and pinned to patched tags; pip/setuptools stripped from the backend runtime image entirely.
  • Per-endpoint rate-limit overrides added, closing a tracked gap; Windows entry points added for two scripts still missing them; the project-story timeline split into smaller per-month files.

Commit 72: 5 September, 2026​

4238bde: "Ran security audit, migrated backend to Alpine, fixed entrypoint and token leak"

A live security audit (Bandit, Semgrep, Trivy, gitleaks, pip-audit, npm audit, a full OWASP ZAP active scan, plus a manual adversarial pentest and a real-browser pass) against a running local-prod-ngrok deployment, re-run clean against a completely fresh rebuild of the stack, followed by fixing what it turned up.

  • Backend base image migrated Debian to Alpine, taking Trivy from 57 High/Critical to 0 on the runtime image; a self-healing entrypoint replaced a manual post-migration volume-fix step.
  • A real login-lockout race fixed: one atomic Redis INCR instead of a check-then-increment pair that let extra failed attempts through under a burst.
  • A real token leak caught in manual review: Procrastinate's job-lifecycle logging was echoing each job's full arguments to stdout, including the raw verification/reset token in send_email_task's email body. Fixed by raising that logger to WARNING.
  • The real Caddy production TLS path tested for the first time, catching a duplicate Strict-Transport-Security header and a gap where the tunnel modes never sent HSTS on the frontend's own pages.
  • Production scaling made configurable (UVICORN_WORKERS/DB_POOL_SIZE/DB_MAX_OVERFLOW); CSP style-src dropped unsafe-inline; an optional off-host backup upload hook added.
  • Full audit re-run clean against the rebuilt images (Bandit/Semgrep/Trivy/pip-audit/npm audit/Gitleaks/ZAP), a fresh manual pentest (17/17 attempts blocked), and a load test finding the real throughput ceiling (~520-560 req/s, Postgres pool saturation past 1,000 concurrent).

Commit 73: 6 September, 2026​

900f799: "Fixed i18n namespace mutation, parameterized Docker multi-fork collision avoidance, patched sync-upstream guidance"

Fixes for issues that surfaced while syncing this template into other downstream forks, plus another issue found live during this session's own CI verification.

  • Fixed translations.ts passing NAMESPACES by reference into i18next.init, letting a downstream app's addResourceBundle mutate it and break the translation-parity test.
  • Added a relocated/deleted-file guard to sync-upstream.sh with a re-diff-and-exclude recipe, plus a regression test.
  • Made Compose project name, host ports, image names, the Bugsink label, Docker subnets, and static IPs required env vars with no fallback across all 5 Compose files, closing a real fork collision found live against a second project on this machine; TRUSTED_PROXY_IPS now derives from those same static-IP vars instead of being set independently.
  • Updated the alembic-merge-heads sync doc to bring the stack up first, since docker compose run --user root doesn't stick past the entrypoint's su-exec.
  • Fixed the tab favicon always regenerating from a user's brand color pick, ignoring branding and added VITE_APP_FAVICON_URL to let a deployment fix its own favicon.

Commit 74: 6 September, 2026​

7b7a0f6: "Restructured .env.example files, added env-tools scripts and agent prompts"

A template-consumer DX pass: made every .env.example scannable, gave template setup, upkeep, and upstream syncing real tooling instead of manual cp/openssl rand/five-file hand edits, then caught and fixed both a test regression and a real data-loss bug the new tooling introduced.

Commit 75: 11 September, 2026​

"Split docker/env into app/mystic_auth, fixed issues from live security/performance audit"

Extended the app/mystic_auth split to docker/ and env/, the two domains that never got it, then ran an independent live audit against the result (real attacker tooling, a 38-attack manual pentest, ZAP, a full 86-test browser pass) instead of trusting it. Found and fixed real bugs at every stage, not just documented them.

  • env/ and the rest of docker/ split into mystic_auth/ + app/, matching every other domain. Two new lints (check-script-paths.sh, check-split-paths.sh) caught 30+ stale-path instances, including three live regressions (alembic/env.py's dead load_dotenv(), conftest.py's same dead path, a stale Playwright helper path).
  • Root Makefile/make.ps1 added, then split the same way; CONTRIBUTING.md, a PR template, an architecture diagram, and missing mermaid diagrams added; check-env.sh/.ps1 now catch a blank BUGSINK_SUPERUSER_EMAIL and a scheme-prefixed NGROK_DOMAIN before either crash-loops the stack.
  • Full audit found 0 exploitable findings (static/dependency/container/secrets scans, ZAP, nmap/nikto/ffuf/sqlmap, the 38-attack pentest, all clean) but surfaced three real bugs: UVICORN_WORKERS defaulting to 1 regardless of host cores (now auto-sizes, +25% throughput/-82% timeouts verified), pg_dump --file=- silently writing 0-byte backups (both db_backup.sh and the new db_restore_drill.sh now avoid it), and a CSS overflow spec quirk showing a stray scrollbar on two pages.
  • Added @axe-core/playwright accessibility scanning (found and fixed 4 real contrast bugs in the default theme), db_restore_drill.sh wired into CI, an opt-in live-deployment Playwright smoke test, and a make lint target. Coverage gate raised 85%->90% (measured: 93.59%). Closed UsersPage.tsx's test gap. Manual dependency updates and secrets rotation documented as deliberate limitations in concerns/README.md.
